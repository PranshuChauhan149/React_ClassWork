# ⚛️ React Class Work  

## 📘 Overview  
This repository contains all the **React.js class work and practice projects** I completed while learning the fundamentals and advanced concepts of React.  
It showcases how I learned to build **dynamic, interactive, and component-based user interfaces** using modern React features.

---

## 🚀 Topics Covered  

### 🧩 Core Concepts  
- JSX (JavaScript XML)  
- Components (Functional & Class-based)  
- Props and State  
- Event Handling  
- Conditional Rendering  
- Lists and Keys  

### ⚙️ Advanced Concepts  
- React Hooks (`useState`, `useEffect`, `useRef`, `useContext`)  
- React Router for navigation  
- Lifting State Up  
- Controlled & Uncontrolled Components  
- Context API for global state management  

### 🎨 Styling in React  
- Inline CSS and External Stylesheets  
- CSS Modules  
- Tailwind CSS / Styled Components  

### 💾 Integration  
- Fetching data from APIs using `fetch()` and `axios`  
- Form handling and validation  
- Using JSON Server / Mock APIs for backend simulation  

---

## 🧠 Objective  
The main goal of this React class work is to understand how React helps in:
- Building reusable UI components  
- Managing application state effectively  
- Creating fast and scalable single-page applications (SPAs)
